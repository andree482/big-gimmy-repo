## 🐍 **FASE 1 – Automazione della gestione immagini (script Python)**

### 🎯 Obiettivo

Prima di iniziare a inserire i prodotti manualmente, ti chiedo di sviluppare uno **script Python dedicato alla gestione intelligente delle immagini** prodotto.

### ✅ Funzionalità richiesta

Spesso i file immagine che ti fornisco hanno **nomi generici o non descrittivi** (es. `34535.png`), mentre corrispondono a prodotti specifici (es. *Ashwagandha*).
Lo script dovrà consentire di:

* Associare in modo univoco il **nome reale del prodotto/variante** al **nome del file immagine**
* Generare un output strutturato che semplifichi e automatizzi il **processo di inserimento delle immagini corrette nelle rispettive schede prodotto**
* Preparare un file di riferimento utile anche per altri operatori che in futuro si occuperanno dell’inserimento

### 📌 Applicazione pratica

A breve ti fornirò un blocco di **19 immagini**.
Tieni presente che:

> ❗ Il numero di immagini non corrisponde necessariamente al numero di prodotti.
> Alcuni prodotti possono infatti contenere **più immagini** (una per ciascuna variante, gusto, o formato).

Per questo motivo, l’automazione tramite Python sarà essenziale per garantire:

* Ordine
* Velocità
* Riduzione di errori
